# Reference tools for the Windows diagnostics case

Checked on November 21, 2026. These are vendor-documented capabilities and one regional storefront price. The head-to-head tests described in the case are planned.

## CapFrameX

CapFrameX records frame timings and exposes captures, statistics and diagnostic tools through a local MCP interface. [Project documentation](https://github.com/CXWorld/CapFrameX#mcp-server-ai-integration)

## Intel PresentMon

The Router candidate used version 2.6.0. Comparing two applications that use this event source can validate their integration. A scene with a controlled frame cadence provides a separate reference for checking accuracy. [Intel release](https://github.com/GameTechDev/PresentMon/releases/tag/v2.6.0)

## FPS Monitor

FPS Monitor displays hardware measurements in-game. The Canadian Steam listing showed C$16.99 on the date above. [Vendor description](https://fpsmon.com/en/) · [Canadian Steam listing](https://store.steampowered.com/app/966610/FPS_Monitor/?cc=ca)
