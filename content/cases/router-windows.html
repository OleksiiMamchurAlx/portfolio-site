Architecture & ownership

I set the diagnostic criteria, reviewed the AI-assisted implementation and checked the outcome on the workstation and VM. The Windows application uses C# and Win32 for the desktop interface and operating-system integration, and Rust for bounded operations with independently checkable results.

The diagnostic handler inventories installed overlay tools and running processes and checks available Windows hardware readings. For a supported Fraps version it can restore a known missing support file after verifying the source hash. A second check reads the resulting state before another write is considered.

Follow the investigation

What did the targeted repair establish?

The expected support file was restored and verified on readback. Fraps still showed its startup error. After I completed the official reinstall, the normal window opened alongside MSI Afterburner and RTSS. The precise cause of the original startup failure remains open.

Could the overlays coexist?

Fraps, RTSS and NVIDIA modules loaded in the same OpenGL test process. It rendered 1,279 frames in 32.023 seconds. I separately observed the counters displaying together on the workstation. The trace records one test application and configuration.

What did the VM test cover?

The exact unpacked 1.0.14.0 consumer candidate ran in a Windows VM. Checks covered the overlay inventory, available hardware readings, the absence of owner-only controls, and a fixed selection that returned the expected IDs in order. The existing Store installation remained at 1.0.13.0 during this test.

Measuring the candidate

In a separate 1.0.15.0 workstation test, the FPS reader measured 39.972 displayed frames per second across 197 frame intervals from one OpenGL application, under a standard Windows account. Eight parser checks passed. The earlier 1,279-frame count above belongs to the overlay-coexistence test.

I checked the unpacked consumer build in a Windows VM and recorded the package fingerprint, component presence and installed Store version. The FPS controls and backend were present. Owner-only components were absent. The VM kept its existing Store installation during that check.

The FPS result applies to this application and capture. A release record ties each check to its build, environment and outcome so a reviewer can repeat it.
