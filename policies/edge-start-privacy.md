# Privacy policy — My Start

Publisher: OLeksii Mamchur.

Extension: Моя стартовая — закладки и вкладки / My Start.

Last updated: 16 October 2026.

Purpose. The extension provides a personal new-tab dashboard. It uses bookmarks and tab titles/URLs to display shortcuts and recent pages. Optional history permission fills the recent-history list. Settings and page caches are stored in the browser profile. There is no developer-operated analytics backend.

Network requests. Bing and Google provide news; Bing provides the daily image. These providers receive ordinary request metadata such as the IP address. Choosing a search provider sends the submitted query to that provider. After explicit user selection, a file or pasted image is staged in the selected provider's page; the provider's own upload processing can begin there. These services have their own privacy policies. File selection is limited to 30 MiB in total. The extension does not sell data or use it for advertising.

Site access. Optional website permissions allow filling the selected provider form and saving eligible visible bookmark screenshots. Screenshots are stored locally. Common account, banking, healthcare and authentication URLs are excluded from automatic screenshot capture, but this filter is not exhaustive. Optional Outlook access reads up to three visible inbox rows after user action and saves a local summary. It does not read mailbox tokens or fetch message bodies. Voice input starts only on user action; the browser's speech service may use a network service. Its provider determines retention of voice input.

Windows module. This separately installed, optional native application reads PC Bluetooth/Wi-Fi/Phone Link state. It provides explicit user-triggered display adjustments. It does not collect SMS contents, authentication codes, passwords or clipboard history. The store package contains no private message samples. If the user enables OneDrive backup, provider/layout/group/pinned-site settings are written to the user's own OneDrive folder by the module. These settings can contain selected site URLs and group names. OneDrive then performs its own sync; the extension does not receive Microsoft account credentials.

Control and deletion. Optional permissions can be revoked in Edge. Local dashboard data is removed when the extension is removed. OneDrive settings must be deleted separately from the user's OneDrive folder. Native host and Phone Link startup are separate Windows components, removable through their provided disable/unregister procedures. Deleting the extension does not automatically delete those Windows files or the user's OneDrive backup.

Questions and data requests: [publisher support](https://github.com/OleksiiMamchurAlx/portfolio-site/issues). Please do not post personal data in public issues.
